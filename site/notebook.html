What the notebook is for

The notebook explores iceberg trajectories using the BYU/NIC-style track data. It is useful for understanding how the local CSVs move over time and for testing trajectory visualization before turning it into a production model.

What it shows visually

  • Iceberg position changes over time.
  • Scatterometer-derived coordinate patterns.
  • How trajectory points can be used for short-horizon drift estimation.
  • How track data can feed route risk and map overlays.

How it fits the demo

The notebook is not the end product. It supports the system by providing trajectory exploration, sanity-checks for the local data, and a place to validate drift assumptions before the route-risk layer uses them.
